# week3_3256

## Database setup

Start Apache and MySQL in XAMPP, then import `php_api/db_shop.sql` using phpMyAdmin. The PHP API connects to the `db_shop` database with the local XAMPP defaults (`root` with an empty password); update these values in `php_api/condb.php` if your MySQL credentials differ.
